# 🚀 NovaCart - Frontend

https://ecommerce-frontend-orcin-two.vercel.app/

Este es el cliente web de NovaCart, una plataforma de e-commerce moderna construida con Next.js 14+ (App Router). Se conecta a la API DE https://dummyjson.com/El proyecto está diseñado bajo principios de Clean Architecture para asegurar escalabilidad, mantenibilidad y desacoplamiento de la lógica de negocio.

### 🛠️ Tecnologías Principales
- Framework: Next.js 14 (App Router)
- Lenguaje: TypeScript
- Estado Global: Zustand (con persistencia en Cookies)
- Estilos: Tailwind CSS + Shadcn/ui
- Validaciones: Zod
- Cliente HTTP: Axios

### ⚙️ Configuración del Entorno
    1. Clonar el repositorio:
```
git clone https://github.com/tu-usuario/novacart-frontend.git
cd novacart-frontend
```

    2. Instalar dependencias:
```
npm install
# o
pnpm install
```    
    3. Ejecutar en desarrollo:
```
npm run dev
```
    La aplicación estará disponible en http://localhost:3000.
